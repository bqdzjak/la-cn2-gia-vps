## 这条洛杉矶线到底怎么走

CN2 是中国电信的 AS4809 承载网，分 GT 和 GIA 两层。GT 出了国门还是要挤 163 骨干，GIA 走独立轻载路径，跳数少、拥塞概率低。晚高峰普通线路延迟从 150ms 涨到 300ms 以上，GIA 通常还能压在 200ms 以内，差别就在这。

Akile 这条线的配置是三网分开的：

- 电信方向标称 CN2 GIA
- 联通方向走 AS9929，联通自己的国际精品网
- 移动方向走 CMIN2，移动的国际优化线路

这跟“三网回程全部强制走 CN2 GIA”是两种东西。后者的意思是联通、移动用户的回程流量也绕到电信的 GIA 上走，前者是三家各用自家最顺手的那条出口。两种方案都能改善晚高峰，但谁更合适取决于你用什么宽带。

电信用户走 GIA，理论上延迟最低；联通用户走 9929，这是联通体系里最好的一档，比普通 163 出口强不少；移动用户走 CMIN2，属于移动的国际优化通道。三家都不是“随便扔一条国际出口”的做法，只是没有统一到同一条线路上。

公开的线路说明里还有一句备注，电信方向“目前走 9929 等电信过白”。这句话说明电信路径还在调整阶段，实际走向可能和标称的不完全一致。介意的话，下单前用官方提供的洛杉矶测试节点跑一遍 traceroute，看你本地到机房到底怎么绕。👉 [注册 Akile 后可查看官方洛杉矶测试入口](https://akile.io/register?aff_code=24a6f6bd-f995-4158-a9fd-f4b6aef27811)
